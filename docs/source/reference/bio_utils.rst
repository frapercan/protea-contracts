Bio utilities
=============

Pure-function biology helpers used by PROTEA ORM models and source
plugins. No SQLAlchemy, no network calls, no side effects.

``parse_isoform`` and ``compute_sequence_hash`` are re-exported from the
top-level ``protea_contracts`` namespace for ergonomic import.
